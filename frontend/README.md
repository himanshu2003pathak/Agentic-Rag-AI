# RAG Agentic Website - Frontend Application

This folder contains the Next.js 16 (App Router) and React 19 frontend for the Educational RAG platform.

## 🎨 Design & Aesthetic Standards

As specified in the PRD and web application development guidelines:
- **Styling**: Strictly **Vanilla CSS with custom properties (`globals.css`)**—no Tailwind CSS.
- **Visual Excellence**: Built with a rich dark mode, vibrant accent gradients, glassmorphism UI components, and modern Google typography (`Inter` and `Outfit`).
- **Animations**: Powered by **Framer Motion** to deliver smooth layout transitions, micro-interactions, and visual feedback during LangGraph agent execution.

## ✨ Key Features

1. **Integrated Chatbox PDF Ingestion**:
   - Students drag and drop or attach PDF files directly into the interactive chat box.
   - Immediate visual feedback shows real-time upload, extraction, chunking, and Pinecone embedding progress.
2. **Interactive RAG Inspector (HITL Mode)**:
   - When the backend LangGraph supervisor pauses execution, a glassmorphic inspector drawer slides out.
   - Students can inspect raw vector dimensions generated by Pinecone, examine retrieved chunks, adjust parameters, and click "Resume Pipeline" to watch generation unfold.

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set environment variables in `.env.local`:
   ```bash
   NEXT_PUBLIC_BACKEND_URL="http://localhost:5000/api/rag"
   ```
3. Run the frontend development server:
   ```bash
   npm run dev
   ```
